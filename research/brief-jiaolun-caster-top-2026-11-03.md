## 1. SEO 基础

### 1.1 主关键词
- **主关键词**：脚轮（搜索量：约 2,000–5,000/月，百度口径；难度：中-高）
  - 说明：作为行业统称词，百度自然搜索量稳定在"脚轮"+"万向轮"+"工业脚轮"+"脚轮厂家"等组合的中高位区间。该词商业意图强（采购意图明确），但 SERP 竞争饱和（百度百科、1688、爱采购、厂家官网混杂）。
  - 百度 SERP 特性：百科+爱采购+厂家站+B2B 平台霸屏，独立内容站需以"长尾+聚合"方式突围。
- **次要主词**：万向轮（约 1,000–3,000/月）、工业脚轮（约 800–2,000/月）、脚轮选型（约 500–1,500/月）
- **域名优势**：脚轮.cn 为精准匹配域名（EMD），主词"脚轮"在站内天然具备权重加成，置顶长文应承担"品类入口页"角色。

### 1.2 语义变体（3–5个）
1. **万向轮 / 活动脚轮 / 定向脚轮**（结构类变体）
2. **聚氨酯脚轮(PU) / 尼龙脚轮 / 铸铁脚轮 / 橡胶脚轮**（材质类变体）
3. **重型脚轮 / 超重型脚轮 / 轻型脚轮**（承重类变体）
4. **静音脚轮 / 耐高温脚轮 / 导电脚轮 / 减震脚轮**（功能类变体）
5. **脚轮厂家 / 脚轮定制 / 脚轮批发**（商业意图变体，用于 CTA 与内链）

### 1.3 长尾机会（2–3个核心长尾 + 拓展）
- **脚轮承重计算方法**（搜索量：300–800/月，难度：低，意图：信息+商业）

### 1.4 "脚轮长尾词"布局思路（必含）
本任务特别要求覆盖"脚轮长尾词"这一概念。建议采用"显性+隐性"双轨布局：

**显性融入（自然出现，不刻意堆砌）：**
- 在文章开头的"导读/导语"段落，自然提及"本文不仅讲脚轮本身，也系统梳理了脚轮长尾词相关的选购维度，包括承重、材质、安装、维护等采购决策中高频检索的细分问题"。
- 在"选购要点"章节设置小节标题如"脚轮选型中的长尾问题：承重、材质、安装如何一次选对"，把长尾词作为章节引导语。
- 在"常见问题 FAQ"或"选购误区"章节，以问答形式承载"脚轮怎么选""脚轮承重怎么算""脚轮什么材质好"等长尾查询。

**隐性融入（语义覆盖）：**
- 在 H2/H3 标题、段落首句、图片 alt、表格列名中自然嵌入"脚轮种类""脚轮材质""脚轮应用场景""脚轮选购要点""脚轮维护保养"等短语，形成语义密度。
- 避免在正文机械重复"脚轮长尾词"字面，而是用"脚轮细分问题""脚轮选型细节""脚轮采购高频问题"等同义表达覆盖相关查询。
